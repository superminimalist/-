# 막장하우스 🎰

코믹 막장 도박판 원카드. 손패 먼저 털면 판돈 싹쓸이.

```
cd makjang-house
node server.js          # http://localhost:8080  (PORT=xxxx 로 변경)
npm test                # 봇끼리 300판 시뮬레이션 — 규칙 엔진 무결성 검사
node build-single.mjs    # 서버 없는 단일 HTML (오프라인 전용) → dist/
```

의존성 0. Node 18+.

## 모드
- **오프라인** — 봇 1~5명. 한 번 접속하면 서비스워커가 캐시 → 인터넷 없어도 실행 (홈 화면에 추가하면 앱처럼).
- **온라인** — 방 만들기 → 4자리 코드/초대 링크 공유. 최대 6명, 빈 자리는 봇. 끊기면 봇이 대신 치고, 같은 브라우저로 재접속하면 자리 복귀. 서버 권위형(패 정보는 본인 것만 전송).

## 룰 요약
- 같은 색 / 같은 숫자 / 같은 기호면 낸다. 턴 20초, 초과 시 자동 드로우.
- 라운드마다 앤티 50씩 상승. 승자 = 판돈 + 패자들 남은 카드 점수만큼 칩. 5라운드 또는 1명 남을 때까지.
- **올인!** — 2장 이하에서 외쳐둘 것. 1장인데 안 외쳤으면 누구나 **신고** → 2장 + 50칩. 외친 놈 신고하면 무고죄 1장.
- **레이즈** — 라운드당 1번, 전원 앤티만큼 추가 베팅.

### 특수카드 12종 (일반 5종 대비 2.4배)
패스 · 역주행 · +2 · **반사** · **바꿔치기** · **동전** · **세무조사** · **시한폭탄** · 와일드 · 와일드+4 · **룰렛** · **판 엎기**
(+2 / +4 / 반사는 서로 쌓기 가능)

### 캐릭터 스킬 7종 (라운드당 1회)
타짜 밑장빼기 · 사채업자 빚 독촉 · 점쟁이 운명 조작 · 건달 떠넘기기 · 딜러 판갈이 · 보험왕 보험 청구 · 도박중독 더블 오어 낫싱

public/             index.html · style.css · app.js · sw.js
